# Shiyi Zhu · Personal Academic Website

Static site (HTML + CSS + vanilla JS), no build step.

- `index.html` – content
- `style.css` – styling
- `script.js` – generative brushstroke hero, scroll reveal, nav
- `assets/portrait.jpg` – optional portrait (add your own; an illustration is shown otherwise)

Deploy: push to GitHub, then Settings → Pages → Deploy from branch → `main` / root.
